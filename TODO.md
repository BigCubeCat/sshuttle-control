# Техничческое задание на графическую обертку sshuttle

## Функциональные требования

На данный момент sshuttle запускается командой

```bash
sudo ./bin/shuttle/run -r user@185.5.74.26 0/0
```

### 1. Проверка состояния

Нужно проверять, запущено ли приложение на данный момент, и проходит ли пинг. Например, до chatgpt.com. Параметр должен быть настраиваемым.

На главном экране должна быть одна большая кнопка и ipv4.
нужно выводить состояние и скорость интернета.


### 2. Настройки параметров

Должна быть страница настроек. в них настраивается:
1. Пароль от ssh или .txt с паролем.
2. ip v4
3. Путь до запускаемой команды (sshuttle)
4. Включение и выключение пинга
5. адрес для пинга
6. Посылать ли dns через sshuttle

Настройки открываются через меню.


## Нефункциональные требования

Приложение не должно сильно нагружать систему
и работать на postmarketos.
Нужно как можно больше кода писать на C++
необходимо настроить .clang-format и .clang-tidy

c++ 20, qt6
